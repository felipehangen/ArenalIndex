# ArenalIndex wordmark

The PNG matches the existing public homepage wordmark: Manrope lettering, dark green arenal and pale green INDEX tag. Captured from the rendered public desktop wordmark at its native size; kept at 140 × 36 px to avoid font substitution in email. The agreement page, broker portal and current invitation/confirmation emails use the same asset. Source reference: arenalindex.com, 2026-11-22.

The site has a responsive HTML wordmark on its homepage; this asset mirrors its desktop appearance. Do not scale the raster above its native dimensions. Email assets use go.arenalindex.com so they are available as soon as the matching email API is deployed.
